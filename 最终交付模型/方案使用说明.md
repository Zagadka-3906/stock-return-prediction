# 37模型研究方案使用说明

此目录保存Stock Return Prediction的多模型研究产物：原生权重ZIP、预测CSV、核验记录和历史报告。项目介绍见[首页](../README.md)，完整指标与来源见[结果页](../docs/RESULTS.md)。

## 方案与输出

方案继承第183轮父方案，加入60日和120日成熟标签网络的一致性信号，新增融合权重0.04、一致性参数0.75、头部保护比例0.15。最终保存37个原生模型，各自承担不同作用。

训练期2020—2024连续向前验证综合分为 **0.4514612196682616**。Rank IC均值0.12280208457197295，Top年化超额0.3735093425702569，平均集合换手0.032374723105348766。这些是历史验证指标，未刷新为独立测试成绩。

`submission.csv`覆盖344日、4,650只股票、1,599,600行，列顺序为`ts_code,trade_date,pred`。

## 文件核验

核对`submission_manifest.json`和`方案包核验.json`，再使用PowerShell计算SHA256：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'submission.csv'
Get-FileHash -Algorithm SHA256 -LiteralPath '赛题五_高分方案_S0.45146122_20261011.zip'
```

CSV应为`18c4c67c7b457eabb3e8c89048df2ae67bc64197b77d0d9e8225ef8a9399f438`；ZIP应为`d3928b57be66ee0747eb0751c22923ff804e2496b32568beb9643594c80ee6d5`。

ZIP包含完整candidate目录、37个原生权重、配置、冻结源码和证据，共16,600个条目，160,925,612字节。原始数据和Python环境不在包内。

历史记录显示原生重载、两次独立全量推理、CSV字节重放和80日冷启动检查通过。复现仍需恢复数据、父方案、环境与冻结脚本路径；解压ZIP不等于跨机器一键重训。步骤见[复现指南](../docs/REPRODUCIBILITY.md)。
