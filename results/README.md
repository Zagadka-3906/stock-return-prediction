## 阅读历史轮次

`optimization_20261003_r*.md`等文件是对应轮次的历史摘要，保留当时的指标、配置和状态。它们不是当前运行说明。旧的“通过”只对应原阶段；后来的清理、测试反馈更正和当前文档不会改写这些快照。

第192轮虽有记录，正式完整榜登记中断，不能据文件存在把它计为完成。评分实例也包含对照与重复，不能解释为独立模型数量。

比较时先核对分数范围、最终输出阶段、已知限制、配置和来源哈希。早期年度均分、连接验证S与测试期回顾分属于不同口径，不应混在同一个排名中。
