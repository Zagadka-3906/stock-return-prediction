# 历史评分目录说明

此目录保存训练验证评分明细与累计排名，用于追溯模型、配置、后处理和对照研究。概览见[结果与产物](../docs/RESULTS.md)。

| 文件 | 内容 |
|---|---|
| `全部训练验证分数明细.csv` | 18,959项评分实例，含对照、复用与重复 |
| `排除已知非因果限制后的训练分数明细.csv` | 按当时数值限制过滤的历史明细 |
| `全程排名.html` | 可在本地浏览器打开的独立累计展示 |
| `optimization_ranking_20261003_r191.json` | 第191轮正式完成快照 |
| `optimization_ranking_20261003_r192.json` | 第192轮中断记录，不表示登记完成 |
| `verification.json` | 来源、核验与交付指针 |

正式评分实例17,753项，另有1,206项已完成原始实例。18,959不是独立模型数量。过滤明细没有排除后来确认的测试期反馈，不能当成独立选模榜；请结合[研究边界](../docs/SELECTION_COMPLIANCE.md)阅读。

v7评分CSV与已核验v5逐字节相同，只更新候选交付位置。排名、推理与封装属于不同状态，第192轮未被本次文档更新补记为完成。

HTML约70MiB，打开需要一定时间；快速查看可用CSV或项目结果页。来源路径按原快照保留。本文2026-11-03重写，原文在`docs/history/local-20261011/全程排名/`，CSV、HTML与JSON保持原样。
