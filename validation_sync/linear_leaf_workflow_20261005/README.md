# 普通树叶与线性树叶的完整方案验证

排名与收益率各三种配置：普通树叶对照、线性树叶lambda=1、线性树叶lambda=10。固定300轮、31叶、深度8、最小叶样本128、学习率0.05及同一种子；63个原始特征的标准化仅使用过去成熟样本，缺失值保留NaN。

六种配置均在真实过去4096行完成48轮预检：叶节点线性系数确实生效，实际导出叶节点公式独立复算预测，缺失值回退、模型重载、不同长度前缀及未来标签扰动均通过。新推理接口也逐位重放了6个线性树模型及10个已有Nyström模型。

正式流程包含30次年度向前训练、6次成熟最终训练及每模型全部1,599,600条未来X检查。第69轮比较124条用途融合方案，第70轮比较138条独立完整方案。生成器实际执行了独立方案胜出和未胜出的分支；合成排序值不是官方评分。

评分前必须先复现真实前轮完整验证向量、官方八指标及未来CSV，再完成新分支检查。最终继续方案冻结、训练期收益映射、官方复核、因果检查、候选推理、完整榜更新及main同步。manifest.json中的实际年度训练列表是提交时快照，其余未完成工作仍明确标为待验证。

资源采样不替换模型拟合函数。14GiB内存启动条件是调度规则，未宣告方法或资源耗尽。数据、权重和原始预测留在本地D盘，必要时使用E盘；GitHub仅保留main。
