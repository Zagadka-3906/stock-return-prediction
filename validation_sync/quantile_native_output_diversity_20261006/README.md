# 两个完整年度的原生输出互补性诊断

2020和2021各1129950行、243日、4650股票，八个模型完整样本外输出键逐位对齐，核对原始文件、训练矩阵、目标、键和标签成熟元数据，以及八个新原生模型的实际300轮。四种分位数目标与既有两种平方损失树和两种岭回归逐日比较原生排序与有效价格行的前10%集合，共两年56组比较，没有读取标签，没有新增拟合或官方分数。

四种目标确实产生不同输出。收益率10%分位数与既有收益率平方损失树的原生前10%重合率为2020年13.48%、2021年8.68%；90%分位数与既有排名树的日均Spearman为-0.328和-0.398。这些是预测差异证据，不构成收益优势。中位数与两侧尾部可进一步作为位置、跨度及风险惩罚的对照方向。

诊断的前10%仅针对价格有效行，用固定人数和股票顺序处理并列，未加载涨停和标签；不是官方指标或换手率。原有20个年度模型及198条完整五年方案评分全部保留，最终采用仍以官方完整收益映射CSV总分决定。没有新增门槛或全局资源边界结论。
