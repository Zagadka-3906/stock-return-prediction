# 全部历史验证

已补齐第 1—60 轮方案、评分、因果检查、候选核验和原始报告。历史独立试验、资源对照、完整榜、旧测试回顾报告与失败／恢复记录也按原始字节归档。

`rounds.csv` 是逐轮索引；`files.csv` / `files.json` 是全部原始文件索引；`manifest.json` 保存压缩包与每轮归档口径。

每个 `evidence_part*.tar.gz` 可用 Python `tarfile` 或常用压缩工具解压。归档已逐文件解压校验 SHA256。较早轮次只保留其当时已有的检查口径。

这是历史文件同步，没有重跑训练或评分。仍在执行的验证将在完整通过后单独同步。原始数据、权重与大型逐行预测 CSV 留在本地，相关路径和哈希保存在冻结协议中。
