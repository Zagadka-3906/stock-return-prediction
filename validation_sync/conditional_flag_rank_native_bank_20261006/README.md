# 涨停组条件排名专用模型：实际训练与核验

三个预定CPU回归配置，7/15/31叶、每个实际64棵树；各自完成2020—2024五个连续向前模型及仅以成熟训练标签拟合的2025最终模型，共18个。训练目标先在每日完整有限标签股票池计算收益排名，再取题面涨停组；沿用原fold_cutoff、一天标签成熟条件与63个因果特征。所有年度实际涨停验证行的原生预测、保存模型重载和独立树遍历逐位相等，同时保留80/260/975日冷前缀、特征与标签对齐检查及模型哈希。

第一次保存的2020模型因原生库不能直接打开中文路径而加载失败。原失败、日志及已训练权重哈希完整保留；恢复通过Python读取UTF8模型文本，核验原始完整树结构相同后复用该次实际拟合，另完成17次新拟合。这里是训练与推理一致性核验，质量分数由独立37方案官方比较产生，不提前宣称方案改善或完成候选资格。

本目录保留源码、原始记录、哈希、分数来源与失败证据；不上传数据、预测数组或模型权重。只使用main。
