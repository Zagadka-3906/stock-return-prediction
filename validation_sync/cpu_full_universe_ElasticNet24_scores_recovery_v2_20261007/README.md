[ElasticNet官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNet.html)。四种固定配置：排序/收益目标分别配alpha=.001/.01，L1比例.5，原生坐标下降最多2000轮，无验证早停。所有目标和特征缩放仅来自对应成熟过去，收益目标先按自身过去.005/.995分位限幅再标准化，预测反变换回目标单位。
