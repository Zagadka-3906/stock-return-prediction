# 同日模型意见分歧的自适应用途权重

两种方向分别保留意见一致或意见分散时的模型权重；只用同日成熟模型预测的股票横截面百分位，不使用标签、未来价格或标签缺失信息。五个年度实际样本外数据的180项非零参数检查与20项关闭门控检查通过，日期前缀逐位一致，未来预测源扰动不会改变早期权重。

源与生成器核验基于当前实际参考图的5个有效用途轴，对应129条预定评分记录；生成器排序控制值为合成值，没有产生新官方质量分。第64轮完整流程已排队，等待第63轮完整验证与执行来源核验通过后，重新冻结实际轴数、参数、模型字节，再进行完整连续向前官方评分、冻结、因果检查、候选推理及完整榜更新。

原型实现通过不表示质量提高；本轮未训练新模型或读取测试标签。所有临时文件均使用D盘，空间不足时才可使用E盘。
