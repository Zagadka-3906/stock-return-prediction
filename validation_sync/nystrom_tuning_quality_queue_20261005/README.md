# 第65、66轮扩展核完整方案流程

第65轮预定172条用途融合记录，第66轮预定218条独立完整主模型记录。原V1生成器发现波次文件名未随编号改变，在任何官方质量评分前失败；原源、冻结与失败记录完整保留。V2实际生成全部三条控制分支：用途融合172条、独立方案未胜出218条、独立方案胜出218条；排序控制值为合成值，未冒充官方分数。

实际图结构来自已冻结第61轮，只用于检查源与生成器。真实评分必须等待第64或65轮完整通过后，重新读取实际赢家，保留有效的同日意见门控，冻结真实参数和全部模型来源。50次年度拟合与10个成熟最终模型的完整未来X、重载和冷前缀核验另行完成，随后才允许评分。

每轮在评分前先复现上一轮5635800行完整验证向量和官方八指标、1599600行未来CSV，再检查全部新增模型的用途或独立方案因果前缀与修改后的完整未来输出。选择后继续收益映射官方复核、候选推理、因果检查、执行来源核验和完整榜更新，再自动推送main。

实际评分代码每个私有上下文覆盖写一份CSV，不保留每条候选的大CSV；当前D盘空间足够。D盘不足时可使用授权E盘，临时目录不使用C盘。有限参数网格与内存调度保留不代表全局优化或物理资源极限。
