# 弃用模型与历史缓存清理

按用户直接删除的要求，删除 4674 个已弃用或历史副本文件，其中模型权重 903 个。逻辑大小 38.76 GiB，D盘空闲量净增加 38.74 GiB。净变化同时受正在运行的训练写入和文件硬链接影响。

逐一复核 12217 份记录，字节 SHA256 保持一致。分数、完整榜、配置、源码和原始数据保留；当前方案及未完成验证的冻结依赖保留。已有清理备份中的实验副本、历史实验权重与预测缓存直接删除，没有再次备份。正在训练的进程没有停止或重启；项目文件未写入C盘。

plan.json为删除前路径、大小、哈希与保留依赖清单，deletions.jsonl为实际逐文件日志，verification.json为核验结果。较大清单使用无损gzip保存。旧验证清单继续作为当时的历史证据，清理后的权重是否仍存在应以本次删除日志为准。冻结验证仍引用的原模型库文件需要保留到相关任务结束，不能据此声称已经删除全部历史权重。
