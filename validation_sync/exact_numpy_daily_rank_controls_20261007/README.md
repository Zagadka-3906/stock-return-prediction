# NumPy按日平均排名实际完整样本检查与测速

三个真实OOF预测向量分别覆盖5635800行、1212个交易日。两种顺序实测共12次排名计算，结果全部与原Pandas函数的float64位值完全相同；每个向量另验80、260、975天冷前缀。

原实现各次中位数1.730259秒，NumPy实现0.341254秒，该操作阶段约快5.070297倍。

并列平均排名、无效价格、NaN、无穷、负九阈值、空输入、乱序日期回退和大整数回退均实测。使用NumPy稳定排序，参考 https://numpy.org/doc/stable/reference/generated/numpy.argsort.html 。
