# 普通树叶与线性树叶的原始预测集成预检

使用已实际训练的15个排名目标年度模型，比较三模型等权、两档线性正则等权、普通树与lambda1线性树等权、普通树与lambda10线性树等权。四种组合均覆盖全部5,635,800条五年OOF记录，且均不同于单个父模型。

真实300轮父模型被序列化为复合模型，重新推理2020年4096条记录并逐位复现完整组合数组；1、80、257、4095条前缀检查全部通过。没有新增模型拟合，也没有新增官方评分。

日排名相关性仅使用有效价格行并不加载收益标签：普通树与线性树均值约0.970/0.971，两档线性正则约0.988；与第64轮完整输出约0.840/0.842。相关性不会成为额外采用门槛。

同样四种权重也预先登记用于收益率目标，共8种集成、40个年度组合输出、8个最终复合模型。第71/72轮完整方案分别计划148/178条官方评分；其完整代码与执行仍待完成。本预检只覆盖排名目标，不能宣称收益率组合或完整方案已验证。

原始Polars表达式构造错误和失败源码保留；异常762TB分配请求不是物理内存边界证据。模型与原始组合数组留在本地，GitHub只上传源码、清单和检查结果。
