# 主分支工作区汇总

全部已上传验证历史与当前源码统一保存在main，后续完整验证也只推送main。这里补充此前未提交的研究报告、运行记录及通过的实际模型计数复核。

大于5 MiB的报告以gzip无损归档，manifest.json记录原始路径、字节数、SHA256及压缩文件位置；每份归档已经实际解压并核对SHA256。其余文件在原目录提交。运行记录是提交时的快照，当前进行中的验证与拟合继续运行，快照不代表它们已经完成。

16384宽度完整训练的两个新增源文件仅通过语法解析，尚未启动，不能算作已完成模型或评分。原始比赛数据、训练权重、预测CSV和运行环境继续存储于本地D盘，必要时使用E盘。
