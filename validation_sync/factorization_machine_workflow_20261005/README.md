# 原始63特征的因子分解机完整方案验证

排名与收益率各三种配置：一阶对照、二阶因子秩8、二阶因子秩32；固定CPU训练32轮、相同AdamW参数及成熟过去样本。参数数分别为64、568、2080，缺失值仅用过去均值填充，收益率截断仅从过去训练窗口学习。

六种真实4096行、4轮预检均通过显式特征对交互公式、解析参数梯度、保存模型重载、不同长度前缀及未来标签扰动检查。两种目标的三档配置预测确实不同。小样本预检不计入实际完整年度拟合或官方成绩。

后续包含30次完整年度拟合、6次成熟最终拟合、全部1,599,600条未来X检查及第73/74轮124/138项完整官方评分。独立方案胜出和未胜出分支的生成器检查通过；合成排序值不是官方分数。

当前正式年度拟合等待14GiB可用主存调度保留量，尚无完整年度拟合。固定CPU避免争用宽网络的GPU显存，资源观察不替换拟合函数；没有宣告方法或物理资源耗尽。既有的全部年序、意见门控、收益映射、因果检查、候选推理及完整榜工作均保留。

模型选择仍只比较连接五年的完整方案官方S。训练验证年份已反复使用，选模偏差未校正；没有使用实际测试标签。原始生成v2源文件保留，新v3修正旧宽度标签及继承集成在精确同分时的分支数。数据、模型和原始预测留在D/E盘。

模型公式依据作者资料：https://www.libfm.org/ ，采用项目自写PyTorch拟合与NumPy原生推理实现。
