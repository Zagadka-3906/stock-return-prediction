# 本机实际GPU资源与续训检查

原FP32小网络32轮与独立进程7+25轮续训完全相同。新BF16微批方案另行完成小网络32轮和实际16384/8192/4096大网络2轮的独立进程重启检查，包含非整除批次；训练损失、全部参数位、预处理、FP32重载预测、固定8192行冷前缀和污染训练输入拒绝均通过。

另在65536条过去成熟训练样本上比较FP32、BF16、TF32三种微批8192/有效批32768方案，每种1次预热和3次计时更新。中位耗时分别约2.401、1.014、1.483秒，采样所见共享显存约0.080GiB。WDDM观测并非连续峰值。原整批32768未复测，子集特征张量更小；以上不证明完整年度加速倍数，也不是年度模型质量评分。新BF16是不同的科学方案，不能继承原FP32年度权重。新年度模型及官方分数均为0。

所有源码、输入哈希、实际日志和失败尝试记录同步至main；大型训练数组与续训文件保留在E盘。
