# GOSS五年完整缓存核验及完整验证流程接入

2020—2024年五个成熟训练窗口分别为1,694,259、2,594,048、3,568,878、4,597,785、5,659,954行，全部63特征。
逐窗口按原GOSS算法重新计算完整列均值、尺度和所有标准化块，逐位及SHA256均与已有缓存一致；两个目标的全部标签、矩阵、股票日期键和成熟边界均与原训练信息一致。
缓存仅只读复用，新增缓存、模型拟合及正式质量记录均为0；69次实际资源观测错误0。

完整GOSS流程已按无窗口方式实际启动并核验存活、源码绑定及原依赖范围。它先等待六个最大窗口的实际6,754,006行、300轮模型及完整1,599,600行未来输入检查全部成功，再冻结并执行原30个年度模型。
后续每个年度模型执行原未来标签扰动控制、全年度重载、独立推理、真实80日及37日冷启动检查；最终再次核对六个原生最终模型的完整未来输入。
原六套参数、样本、目标和迭代数保持一致，不因内存改变模型；六个最终模型复用实际拟合证据，文件复制不计新增拟合。

12 GiB最大窗口启动要求仍是调度策略，不是物理资源边界；目前最大窗口实际进程仍在等待可用内存。
年度流程的启动余量将来自六个最大窗口的实际资源观测，并增加2 GiB余量且至少6 GiB，不依据质量分数选择资源条件。
原GPU训练、质量验证及发布进程继续运行。原第75/76轮父方案74/75、124+138共262个正式质量方案均保留；正式选模、冻结、因果检查、候选推理和完整榜更新仍待完成。

新流程尚未向旧质量模型路径暴露模型或通过标记；旧待办保留，完整原生范围实际成功后另行核验接管，避免制造原执行成功记录。
本次只证明五年缓存与实际等待流程接入，不声称30+6模型或262方案完成，不读取TestY，不宣布全局优化边界。全部代码、成功核验和实际启动快照只上传main。
