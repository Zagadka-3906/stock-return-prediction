# 每轮验证的方案同步

[全部历史验证](history/README.md) 已补齐第 1—60 轮及其原始验证记录。每轮目录保存方案参数、指标和证据，`latest.json` 指向最新完成轮次。

后续轮次只有在官方评分、方案冻结、因果检查、候选推理与来源核验完成后才自动提交。同步器依赖本地主机与进程运行；恢复后会补齐未同步的已完成轮次。
