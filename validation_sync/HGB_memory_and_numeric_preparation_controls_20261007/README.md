# 全股票池HGB实际样本内存范围与分块预处理检查

2020至2025六个成熟窗口逐一统计，最终2025训练6754006行。Float64原特征矩阵、原有预处理临时矩阵和保留的Polars数值表，在最终窗口预处理阶段合计至少约14.27GiB，尚不含键、标签、验证矩阵和其他进程。原门槛为12GiB。这是源码分配与实际行数推导；小矩阵C/F布局的NumPy内存分配也实测，未声称实际OOM或全局资源穷尽。

8192行分块调用原预处理函数，保持原中位数、均值、标准差及计算顺序。372000行真实历史63特征的F64、C64、F32、非连续视图四种布局，分别两种相反顺序实测；输出float64位值、输入未修改、8192行跨块前缀及缺失、无穷、负零控制均通过。前缀计数是行数，不是交易日。

F64布局旧实现额外tracemalloc峰值约536MiB，分块约191MiB；这些数字不含原输入、Polars表和其他进程。本记录尚未在已封存HGB24训练任务中采用新实现，没有新模型训练或选模评分。完整6754006行训练输入和24个原生模型验证仍须实际执行。
