# 数据指南

本项目处理股票日频面板。一行对应一只股票在一个交易日的观测，主键是 `(ts_code, trade_date)`。模型在当日行情完整可用之后形成预测，目标是数据提供方定义的未来一天收益标签。

## 数据范围

| 数据 | 时间范围 | 股票数 | 交易日 / 行数 |
|---|---|---:|---:|
| 原始训练面板 | 2018-01-02—2024-12-31 | 4,650 | 7,900,350 行 |
| 连接验证面板 | 2020—2024 | 4,650 | 1,212 日 / 5,635,800 行 |
| 已记录预测输入 | 2025-01-02—2026-06-08 | 4,650 | 344 日 / 1,599,600 行 |

这些是现有研究的实际规模，不是运行代码所需的固定日期。代码中的窗口、日期和面板假设仍需在迁移数据时逐项检查。

## 字段约定

| 字段 | 含义 | 源码读取类型 | 训练 | 预测 |
|---|---|---|:---:|:---:|
| `ts_code` | 股票代码，保留原始字符串 | String | ✓ | ✓ |
| `trade_date` | 交易日期，格式 `YYYYMMDD` | Int32 | ✓ | ✓ |
| `open` | 当日开盘价 | Float32 | ✓ | ✓ |
| `high` | 当日最高价 | Float32 | ✓ | ✓ |
| `low` | 当日最低价 | Float32 | ✓ | ✓ |
| `close` | 当日收盘价 | Float32 | ✓ | ✓ |
| `vol` | 成交量 | Float32 | ✓ | ✓ |
| `amount` | 成交金额 | Float32 | ✓ | ✓ |
| `flag_limit_up` | 涨停标记，`0` 表示未涨停 | Int8 | ✓ | ✓ |
| `flag_limit_down` | 跌停标记 | Int8 | ✓ | ✓ |
| `y_ret_1d` | 数据提供方的一天收益标签 | Float32 | ✓ | — |

量额单位、价格复权方式和标签对齐方式应与数据提供方保持一致。源码没有替你确认这些语义，也不自动把不同来源的字段转换成相同市场口径。接入自有数据时应先记录这些约定。

输入文件的表头为：

```csv
ts_code,trade_date,open,high,low,close,vol,amount,flag_limit_up,flag_limit_down,y_ret_1d
```

预测文件使用相同行情表头，省略最后的标签列即可。文件默认位置为 `data/raw/训练集.csv` 和 `data/raw/测试集_X.csv`。

## 排序、完整面板与缺失值

基础特征代码先按 `ts_code,trade_date` 排序，让滚动和滞后只作用于同一只股票。横截面排名按 `trade_date` 分组，因此使用的是同一天的股票集合。模型推理按日期、股票排列计算，最后通过 `row_id` 恢复预测输入顺序。

固定集成的推理实现要求完整矩形面板，即每日拥有同一组股票，行数等于日期数乘股票数。股票代码与日期的组合也必须唯一。自己的数据如果存在不同上市日期、停牌空档或动态股票池，需要先设计合适的面板处理并调整相应假设，不能只删除缺失行后沿用原推理逻辑。

`src/features.py` 将空文本、`NaN`、`nan` 解析为缺失；非正价格转换为空值；除法在分母过小时返回空值。滚动窗口不足会留下缺失特征。各模型的处理方式应依其实现与冻结配置核对，不能统一把所有缺失填成零。

评分时缺失标签的过滤属于评分定义：IC 和超额收益会过滤标签缺失，集合换手不会额外做该过滤。见[方法详解](METHODS.md#评分定义)。

## 缓存和特征清单

| 文件 | 内容 |
|---|---|
| `data/features.parquet` | 63 项基础特征与主键、行号、训练标记等元数据 |
| `data/feature_manifest.json` | 特征顺序、数量、Qlib 公式与输入行数 |
| `data/peer_features.parquet` | 固定集成使用的基础面板与同伴特征 |
| `config/features.json` | 固定基准读取的基础特征顺序 |

缓存主要用于避免重复计算。文件存在不等于与当前原始数据同源；更换数据、特征实现或字段语义时，应在新目录建立完整的新产物链，并记录数据与配置哈希。

## 输出预测的语义

```csv
ts_code,trade_date,pred
```

| 路线 | `pred` 是什么 |
|---|---|
| 固定 LightGBM 基线143 | 直接回归一天收益的模型原生输出，使用收益率小数 |
| 根目录固定 XGBoost 基准 | 后处理排名的仿射变换；有效值为 `0.04 × (ranked − 0.5)` |
| 37 模型研究方案 | 经该方案训练期收益映射后的最终预测 |

预测值为正不等于实际一定上涨，横截面排名也不天然对应可交易仓位。后续分析应先确认路线，再选择与其语义相符的评估方式。

## 数据分发

普通 Git 克隆不包含原始 CSV。仓库没有提供自动下载原始数据的脚本或一个可代替原数据的公开镜像。数据的取得与使用范围应依据其原始来源；模型源码公开可读也不自动授予数据再分发权限。
