# 固定 LightGBM 直接收益基线

这条路线使用63项基础量价特征，直接回归一天收益，最终只使用一个LightGBM模型推理。固定配置与无额外后处理的设计，适合用来理解数据时间边界和完整验证流程。历史编号为“基线143”。

## 模型设计

| 项目 | 配置 |
|---|---|
| 特征 | 原63项量价与横截面特征 |
| 目标 | 原始训练集 `y_ret_1d` |
| 模型 | LightGBM，31叶，180轮，学习率0.05，种子2026 |
| 候选数量 | 本轮预先指定一个候选 |
| 后处理 | 无；输出模型原生收益预测 |
| 验证 | 2020—2024逐年向前，按日期连接 |
| 最终推理 | 1个模型；另保留5个年度验证模型 |

本轮训练不继承旧集成的赢家、教师信号、成员与排序分离或后处理。架构与特征名有测试收益揭示前的哈希锚点，但新的直接收益目标与完整执行协议在2026-10-11才冻结，不能将整个方案描述成更早已固定。

## 时间与计算检查

年度训练要求标签结束日期严格早于验证开始；最终拟合排除训练末日标签。特征计算前移除标签列，滚动仅使用本股票当前和过去行情，横截面排名使用同日数据。

历史执行记录显示：模型重载、全量CSV重放和80日特征/预测前缀一致性通过。推理曾修复两处实现问题：历史与预测输入的连接列顺序不一致；原始文件按股票排列时，前缀核验错误地依赖物理行序。v2对齐列，v3改为按日期筛选原文件位置后比较。原协议、训练与评分代码及失败记录均保留。

## 从已有材料重现推理

需要完整工作目录中的协议、冻结记录、`model_final.txt`等材料，以及原始训练和预测行情。仅克隆源码后建立空工作目录，不能直接运行以下命令。

```powershell
python -B -X utf8 analysis/train_only_baseline143_inference_v3_20261011.py --stage infer --work-dir 'D:/复现材料/基线143' --train-csv 'D:/数据/训练集.csv' --test-x 'D:/数据/测试集_X.csv'
```

推理需LightGBM、NumPy和Polars；评分另需Pandas、SciPy和Loguru。原脚本有协议、源码哈希与执行控制检查，迁移前应先阅读相关代码和[复现指南](REPRODUCIBILITY.md)。

训练、评分和最终训练由 `analysis/train_only_baseline143_v1_20261011.py` 的 `train`、`score`、`final` 阶段完成。`freeze` 阶段依赖原历史架构锚定目录；已有协议不应覆盖。历史全量训练生成约1.7GB特征缓存。
